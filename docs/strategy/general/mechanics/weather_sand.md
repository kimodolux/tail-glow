# Sand

- Set by: Sandstorm (move) or Sand Stream (ability)
- Rock types: 1.5x Sp.Def
- Damages non-Rock/Ground/Steel each turn
- Sand Rush: Doubles Speed
- Key users: Tyranitar, Hippowdon, Gigalith
- Counter: Set opposing weather, use immune types
